# Набор изображений: явная утечка масла

Пять синтетических кадров одного насоса с заметной утечкой у приводного узла. В каждом изображении показаны путь масла от узла до пола и растекающаяся лужа. Освещение различается: дневное, холодное LED, тёплые лампы, переносной рабочий свет и ночной прожектор.

Изображения предназначены для визуальной проверки модели. Это не фотографии реальной аварии; точная модель насоса по референсам не подтверждена. Описания и сведения о генерации находятся в `generation-manifest.json`.
